Design

设计原理

用尽量少的抽象覆盖多智能体协作与可扩展工具。

01

Agent as Tool

子智能体实现与普通工具相同的接口。对 Manager 而言，委派任务就是一次函数调用； 对成员而言，仍是完整的多步 ReAct 循环与独立记忆。

02

Everything is a Plugin

ToolRegistry 是唯一的能力目录。内置插件、动态工具、乃至未来的扩展都以同一接口注册与发现， 没有第二套「特殊工具」通道。

03

Runtime Authorship

元插件 create_tool 允许模型用 shell 模板为自己编写新工具，注册后立即可用。 目录可增长，而不是写死在启动配置里。

04

Sandboxed Workspace

文件与 shell 操作被限制在 workspace 内：路径逃逸被拒绝，命令带超时与精简环境变量， 降低误操作与失控风险。

Get started

快速开始

Go 1.22+，配置 API 后一条命令即可运行。

terminal 
# 克隆与配置
git clone https://github.com/1parado/tiny-team.git
cd tiny-team
cp .env.example .env

# 运行
go run . -task "在 workspace 写 hello.txt 并读回来"

# 可选：轨迹 UI · 自定义沙箱
go run . -web :8765 -workspace ./myws
